## Extension contract

Use the protocol rather than editing files by hand:

```bash
omniagi extend <name> --purpose "<one line>" [--script omniagi/<name>.py]
```

That single command:

1. detects the gap (refuses if the tool is already registered),
2. writes `tools/<name>.md` from the spec template,
3. registers the tool in `registry/harness.json`,
4. regenerates every derived table,
5. verifies by reading the registry and spec back off disk, and
6. appends a deduplicated line to `memory/CHANGELOG.md`.

Verification failure aborts the extension: a tool is never logged as added
unless its presence was proven by read-back. See `workflows/tool-extension.md`.

## Deprecation

Set `"status": "deprecated"` in `registry/harness.json`, move the spec to
`tools/archive/`, and log the change. Never silently delete.
